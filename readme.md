# JPEG2000 Full Pipeline - Leon Liang and Lucas Schattenmann

## How to Use
Run jpeg2000.py file with Python.

## Parameters
* `--wavelet`: Choose which wavelet to use with DWT from following list:
* `--quality`: Select a quality value from 0-100 to affect fidelity of final reconstruction.
* `--block_size`: Select block size to divide each component into.
* `--output`: File to output encoded binary bitstream to.
* `--recon`: File to save reconstructed image as.
